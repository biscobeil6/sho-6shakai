# 小6社会 書答式アプリ v0.2.1

- 問題数: 631問（A型 600 / B型 31）
- 元データ: `穴埋め問題_全学年_統合.csv`
- 出題対象カード: 654枚
- 手書き入力: 中3社会 v3.7.0 の iPad 調整済み Canvas 処理・サイズを継承
- 自己採点: ○ / △ / ×
- 絞り込み: 学年 / 分野 / 6年歴史の時代 / ★必修 / A・B
- 出題数: 10 / 20 / 50 / 一周
- 復習: △・×のみ
- 参考: 用語マスターを「用語ノート」としてアプリ内閲覧可能

## 起動
GitHub Pages 等の静的Webサーバーにこのフォルダ内をそのまま配置してください。`fetch()` を使うため、iOSの「ファイル」から `index.html` を直接開く方式ではなく、Webサーバー経由を推奨します。

## 資料PDFについて
v0.2.1では、小6社会の完成ノート（全179ページ）をPDFとして同梱し、アプリ内の「資料ノート」から閲覧できます。必要に応じて「PDFを大きく開く」で別画面表示もできます。
